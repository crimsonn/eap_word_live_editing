# EAP Word Math Editor – MCP server για το Claude Desktop

Το εργαλείο αυτό δημιουργήθηκε για τους φοιτητές του **Ελληνικού Ανοικτού Πανεπιστημίου (ΕΑΠ)**, ώστε να μεταφέρουν εύκολα τις χειρόγραφες λύσεις τους στο Word. Φωτογραφίζετε τη σελίδα σας, τη δίνετε στο Claude, και εκείνο γράφει το κείμενο και τις εξισώσεις απευθείας στο έγγραφό σας. Δεν χρειάζεται να πληκτρολογήσετε κάθε κλάσμα, πίνακα και ολοκλήρωμα με το χέρι.

Επιτρέπει στο Claude να εισάγει κείμενο και **εγγενείς εξισώσεις του Word** (γραμμένες σε LaTeX) στο έγγραφο Microsoft Word που έχετε ανοιχτό. Λειτουργεί σε **macOS** και **Windows**, καθώς ο server αναγνωρίζει αυτόματα το λειτουργικό σύστημα.

Εργαλεία που παρέχει:

| Εργαλείο | Τι κάνει |
|---|---|
| `insert_text` | Εισάγει απλό κείμενο σε νέα γραμμή, στη θέση του cursor |
| `insert_equation` | Εισάγει μια συμβολοσειρά LaTeX σε νέα γραμμή ως εξίσωση του Word |
| `get_platform` | Δείχνει αν ο server τρέχει σε macOS ή σε Windows |

---

## Απαιτήσεις

- **Εφαρμογή Microsoft Word για υπολογιστή** με υποστήριξη εξισώσεων LaTeX (Microsoft 365 ή Word 2021 και νεότερο). Το Word για το web δεν υποστηρίζεται.
  - Οι φοιτητές του ΕΑΠ μπορούν συνήθως να εγκαταστήσουν δωρεάν το Microsoft 365 με τον ιδρυματικό τους λογαριασμό. Δείτε τις οδηγίες του Πανεπιστημίου.
- **Python 3.10 ή νεότερη**
- **Claude Desktop**

---

## 1. Εγκατάσταση των πακέτων Python

Αποθηκεύστε το `word_math_server.py` σε έναν φάκελο που θα κρατήσετε μόνιμα, για παράδειγμα:

- macOS: `~/mcp/word-math-editor/`
- Windows: `C:\mcp\word-math-editor\`

Στη συνέχεια εγκαταστήστε τις εξαρτήσεις.

**macOS** (Τερματικό):

```bash
cd ~/mcp/word-math-editor
python3 -m venv .venv
.venv/bin/pip install fastmcp
```

**Windows** (PowerShell):

```powershell
cd C:\mcp\word-math-editor
python -m venv .venv
.venv\Scripts\pip install fastmcp pywin32
```

Το εικονικό περιβάλλον (`.venv`) κρατά τα πακέτα ξεχωριστά από το υπόλοιπο σύστημα και σας δίνει μια σταθερή διαδρομή για την Python, που θα χρειαστεί στο επόμενο βήμα.

## 2. Προσθήκη του server στο Claude Desktop

1. Ανοίξτε το Claude Desktop και πηγαίνετε στις **Settings → Developer → Edit Config**.
   Ανοίγει το αρχείο `claude_desktop_config.json`:
   - macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
   - Windows: `%APPDATA%\Claude\claude_desktop_config.json`
2. Προσθέστε τον server κάτω από το `mcpServers`. Χρησιμοποιήστε **πλήρεις διαδρομές** και αντικαταστήστε το `YOURNAME` με το όνομα χρήστη σας.

**macOS:**

```json
{
  "mcpServers": {
    "word-math-editor": {
      "command": "/Users/YOURNAME/mcp/word-math-editor/.venv/bin/python",
      "args": ["/Users/YOURNAME/mcp/word-math-editor/word_math_server.py"]
    }
  }
}
```

**Windows** (προσέξτε τις διπλές ανάστροφες καθέτους `\\`):

```json
{
  "mcpServers": {
    "word-math-editor": {
      "command": "C:\\mcp\\word-math-editor\\.venv\\Scripts\\python.exe",
      "args": ["C:\\mcp\\word-math-editor\\word_math_server.py"]
    }
  }
}
```

Αν το αρχείο έχει ήδη άλλους servers στο `mcpServers`, προσθέστε το `"word-math-editor": { ... }` δίπλα τους, χωρισμένο με κόμμα.

3. Αποθηκεύστε το αρχείο και **κλείστε εντελώς και ανοίξτε ξανά το Claude Desktop** (σε macOS: Claude → Quit, όχι απλώς κλείσιμο του παραθύρου).
4. Ελέγξτε ότι ο server εμφανίζεται στις **Settings → Developer** χωρίς σφάλματα.

## 3. Μόνο για macOS: παραχώρηση δικαιωμάτων

Σε macOS ο server πληκτρολογεί στο Word με προσομοιωμένα πλήκτρα, κάτι που το macOS μπλοκάρει μέχρι να το επιτρέψετε.

1. Ανοίξτε τις **Ρυθμίσεις συστήματος → Απόρρητο και ασφάλεια → Προσβασιμότητα** (System Settings → Privacy & Security → Accessibility).
2. Ενεργοποιήστε το **Claude**. Αν δεν εμφανίζεται, προσθέστε το με το **+** από τον φάκελο Εφαρμογές.
3. Την πρώτη φορά που θα τρέξουν τα εργαλεία, το macOS μπορεί να ρωτήσει αν το Claude επιτρέπεται να ελέγχει το **Microsoft Word** και τα **System Events**. Πατήστε **OK** και στα δύο. (Μπορείτε να τα ελέγξετε αργότερα στο **Απόρρητο και ασφάλεια → Αυτοματοποίηση**.)
4. Κλείστε και ανοίξτε ξανά το Claude Desktop αφού αλλάξετε αυτές τις ρυθμίσεις.

Αν δείτε το σφάλμα `osascript is not allowed to send keystrokes`, λείπει το δικαίωμα Προσβασιμότητας.

Στα Windows δεν χρειάζονται επιπλέον δικαιώματα.

## 4. Ενεργοποίηση του LaTeX στο Word

Από προεπιλογή, το Word διαβάζει τις εξισώσεις ως **UnicodeMath**. Αλλάξτε το μία φορά σε **LaTeX**, ώστε να αναγνωρίζονται εντολές όπως `\frac`, `\sqrt` και `\begin{bmatrix}`.

1. Ανοίξτε ένα έγγραφο και εισαγάγετε μια εξίσωση:
   - macOS: **Εισαγωγή → Εξίσωση** (Insert → Equation) ή πατήστε **Ctrl + =**
   - Windows: **Εισαγωγή → Εξίσωση** (Insert → Equation) ή πατήστε **Alt + =**
2. Εμφανίζεται η καρτέλα **Εξίσωση** (Equation) στην κορδέλα.
3. Στην ομάδα **Μετατροπές** (Conversions), επιλέξτε **LaTeX** (αντί για UnicodeMath).
4. Διαγράψτε την κενή εξίσωση.

Το Word θυμάται αυτή τη ρύθμιση, οπότε συνήθως τη κάνετε μόνο μία φορά ανά υπολογιστή.

**Αν οι εξισώσεις εμφανίζονται ως ακατέργαστος κώδικας** (π.χ. `\frac{x^3}{3}` αντί για κλάσμα): κάντε κλικ μέσα σε οποιαδήποτε εξίσωση και στην καρτέλα Εξίσωση επιλέξτε **Μετατροπή → Όλες – Επαγγελματική** (Convert → All – Professional). Έτσι μετατρέπονται όλες οι εξισώσεις του εγγράφου μαζί.

## 5. Χρήση

> **Σημαντικό: το Word πρέπει να είναι ανοιχτό.** Ο server δεν ανοίγει μόνος του έγγραφο. Γράφει στο έγγραφο του Word που είναι ήδη ανοιχτό, στη θέση του cursor.

1. Ανοίξτε το Word με το έγγραφο στο οποίο θέλετε να γράψει το Claude και κάντε κλικ στο σημείο όπου θέλετε να μπει το περιεχόμενο.
2. Στο Claude Desktop, ζητήστε για παράδειγμα:
   > Πρόσθεσε μια ενότητα με τίτλο «Μαθηματικά» και μετά εισήγαγε τις εξισώσεις από αυτή τη φωτογραφία με τον επεξεργαστή εξισώσεων του Word.
3. Αφήστε το παράθυρο του Word διαθέσιμο όσο το Claude εισάγει περιεχόμενο. Σε macOS, μην πληκτρολογείτε και μην αλλάζετε παράθυρο κατά την εισαγωγή, γιατί τα πλήκτρα πηγαίνουν στην εφαρμογή που βρίσκεται μπροστά.

### Ένα ή περισσότερα έγγραφα ανοιχτά;

Το Claude γράφει πάντα στο **ενεργό έγγραφο**, δηλαδή στο παράθυρο του Word που χρησιμοποιήσατε τελευταίο. Δεν μπορεί να επιλέξει έγγραφο με βάση το όνομά του.

- **Συνιστάται:** να έχετε ανοιχτό **μόνο ένα έγγραφο Word** όσο το Claude εισάγει περιεχόμενο. Έτσι δεν υπάρχει περίπτωση να γράψει σε λάθος αρχείο.
- Αν χρειάζεστε περισσότερα έγγραφα ανοιχτά, κάντε κλικ μέσα στο σωστό έγγραφο, στο σημείο που θέλετε, **ακριβώς πριν** ζητήσετε κάτι από το Claude, και μην αλλάζετε έγγραφο μέχρι να τελειώσει.

## Αντιμετώπιση προβλημάτων

| Πρόβλημα | Λύση |
|---|---|
| Ο server δεν εμφανίζεται στο Claude Desktop | Ελέγξτε ότι οι διαδρομές στο config είναι πλήρεις και σωστές και ότι το JSON είναι έγκυρο, και μετά κάντε πλήρη επανεκκίνηση του Claude Desktop. |
| `osascript is not allowed to send keystrokes` (macOS) | Δώστε δικαίωμα Προσβασιμότητας στο Claude (βήμα 3). |
| `Microsoft Word is not running` (Windows) | Ανοίξτε το Word και ένα έγγραφο πριν ζητήσετε κάτι από το Claude. |
| Το περιεχόμενο μπήκε σε λάθος έγγραφο | Το Claude γράφει στο ενεργό έγγραφο. Κλείστε τα υπόλοιπα έγγραφα ή κάντε κλικ μέσα στο σωστό πριν ξεκινήσετε (βήμα 5). |
| Οι εξισώσεις εμφανίζονται ως κώδικας LaTeX | Ορίστε τις Μετατροπές σε LaTeX και μετά **Μετατροπή → Όλες – Επαγγελματική** (βήμα 4). |
| Το κείμενο μπαίνει μέσα στο πλαίσιο της προηγούμενης εξίσωσης | Ο cursor δεν βγήκε από την εξίσωση. Σε macOS, προσθέστε μια δεύτερη γραμμή `key code 124` στο `_MAC_EQUATION_SCRIPT`· σε Windows, αλλάξτε το `sel.SetRange(end, end)` σε `sel.SetRange(end + 1, end + 1)`. |
| Μια εξίσωση δείχνει κάποια εντολή ως απλό κείμενο (π.χ. `\overset`) | Το Word δεν υποστηρίζει όλες τις εντολές LaTeX· χρησιμοποιήστε ένα απλούστερο ισοδύναμο. |
| Οι ελληνικοί τόνοι δεν εμφανίζονται σωστά | Βεβαιωθείτε ότι το αρχείο `word_math_server.py` είναι αποθηκευμένο σε κωδικοποίηση UTF-8. |
